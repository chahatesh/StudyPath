Version 1.3
April 2026
Latest

🔁ImprovedNavigation bar — removed clutter. Settings gear and What's New are clearly signposted.

Version 1.2
March 2026
🧑‍🏫NewTeach Mode v2 — 3-step flow: learn → active recall → confidence rating. AI-generated analogies and Socratic questioning for every learning style.
🔁NewRetry Pile — wrong answers come back at the end of every quiz. You must answer them correctly before your final score appears.
⚡NewTimed Mode — 30-second countdown ring per question. Scoring 80%+ on a quiz automatically activates timed mode next run.
📊NewSpaced repetition — questions you get wrong most often are surfaced first in future quiz sessions automatically.
🏆NewMastery badges — score 80%+ on any quiz to earn a gold mastery badge on its card.
🔀ImprovedAnswer shuffling — multiple choice options are now shuffled each time so memorising position doesn't work.
🧠
Version 1.1
February 2026
🧠NewLearning style quiz — 8-question VARK assessment that personalises every quiz, explanation and teach session to your style.
∞NewInfinite Mode — endless shuffled questions with a live counter. Results are shown when you choose to stop.
🔥NewFirebase live sync — questions added by the creator appear instantly for all users without a page refresh.
📐ContentMagnetism & Electromagnetism — full 40-question banks for Chapters 19 and 21 added.
🔑NewSession auth — creator password now grants a 30-minute session so you don't have to re-enter it between questions.
🚀
Version 1.0
January 2026
🎉NewStudyPath launched — subject grid, quiz engine with MCQ and short-answer support, answer review, XP and streak tracking.
📝NewNotes view — each quiz has a notes panel with key concepts and a full question-by-question explanation breakdown.
📚ContentSubjects added — Math, Science, US History and English loaded with starter question banks.
⚙️NewCreator tools — password-protected panel to add, edit, import and delete questions, subjects and quizzes in real time.
💬NewQuestion requests — email system so any student can request new questions for any topic.
